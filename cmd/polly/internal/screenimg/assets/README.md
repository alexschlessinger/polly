# Screenshot fallback font

`DejaVuSansMono.ttf` is the unmodified regular face from
[DejaVu Fonts 2.37](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37),
extracted from `dejavu-fonts-ttf-2.37.tar.bz2`. It supplies TUI symbols when
system fonts and Go Mono do not cover them. The upstream license is included
in `LICENSE-DejaVu.txt`.
